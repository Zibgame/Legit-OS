# LEGIT OS

Arch-based offensive-security environment focused on modern penetration
testing, Hack The Box and exploit development.

The live image stays desktop-neutral. During installation, `legit-install`
offers GNOME, Hyprland, KDE Plasma, XFCE or a terminal-only system. Each choice
has an isolated package list: selecting GNOME, for example, installs no
Hyprland package or configuration. Quickshell and user dotfiles remain
entirely user-owned.

## Security toolkit

The package selection follows the useful scope of Kali's default and topical
metapackages without copying obsolete or redundant tools.

- Discovery: Nmap, Masscan, RustScan, Naabu, Amass, Subfinder and httpx.
- Web: Burp Suite Community, ZAP, ffuf, Feroxbuster, Gobuster, Nuclei,
  SQLMap, WPScan, Dirsearch, WAFW00F, WhatWeb, Arjun and Dalfox.
- Active Directory: NetExec, Impacket, Responder, BloodHound CE collector,
  Certipy, enum4linux-ng, Evil-WinRM, Samba and FreeRDP.
- Pivoting: Ligolo-ng, Chisel, ProxyChains, Socat, OpenVPN and WireGuard.
- Privilege escalation: PEASS-ng and pspy.
- Passwords: Hashcat, John, Hydra and Medusa.
- Exploitation and binary work: Metasploit, ExploitDB, pwntools, GDB,
  pwndbg, GEF, Ghidra, Rizin, Radare2, Ropper and checksec.
- Network and wireless: Wireshark, tcpdump, Bettercap and Aircrack-ng.
- Forensics and analysis: Binwalk, YARA, Volatility 3, Sleuth Kit, Foremost,
  ExifTool, JADX, apktool and Trivy.
- Wordlists: SecLists and common password wordlists.

Official Arch packages are listed in `packages/offensive-tools.list`. Important
maintained tools absent from the official repositories are isolated in
`packages/aur-tools.list`; the build creates them as an unprivileged user and
embeds the resulting signed-off local repository in the ISO. Archinstall uses
those same compiled artifacts, so the live and installed systems contain the
same toolkit without compiling AUR packages on the target.

## User configuration policy

- No `.zshrc`, `.vimrc`, shell profile or desktop configuration is installed,
  replaced or edited by the image.
- Vim, NERDTree and vim-devicons are installed system-wide, so a personal
  `.vimrc` remains optional and NERDTree icons are available.
- Every font in Arch's official `nerd-fonts` group is installed. The group is
  expanded dynamically during the build so new official Nerd Fonts are picked
  up automatically.
- The LEGIT wallpaper is installed at
  `/usr/share/backgrounds/legit/ocean-balcony.jpeg`.
- `legit-personalize` optionally applies that wallpaper using an already
  installed desktop backend. For an existing Hyprland config it changes only
  the `autogenerated` warning marker; it never creates a Hyprland config.

## Build

Requirements on Windows: Docker Desktop, Git Bash and optionally VirtualBox.

```bash
make       # build the container and ISO
make re    # rebuild container and ISO without Docker cache
make vm    # boot the latest ISO in the existing VirtualBox workflow
```

The generated ISO is written to `out/` (the Makefile may map it to the
configured external output directory). The build starts from Archiso's current
official `releng` profile, layers the small LEGIT overlay, builds the selected
AUR tools, expands the Nerd Fonts group, and finally runs `mkarchiso`.

## Installation

Run `legit-install` from the live environment, choose GNOME, Hyprland, KDE,
XFCE or no graphical environment, then finish the normal Archinstall screens.
Disk layout, bootloader, encryption and user creation remain interactive.
The GNOME profile includes GNOME Terminal, GNOME Console and Ptyxis, covering
the classic, minimal and container-oriented GNOME terminal applications.
For an unattended desktop choice, use for example
`legit-install --desktop gnome`; `--print-config` displays the generated preset
without starting an installation.

The installed system includes OpenVPN, the NetworkManager OpenVPN plugin,
OpenConnect and WireGuard. `legit-vpn lab.ovpn` connects in the terminal;
`legit-vpn --import lab.ovpn` imports the profile into NetworkManager.

The compiled AUR repository is carried by the ISO and enabled only for the
duration of installation. It installs NetExec, Nuclei, ffuf, Feroxbuster,
Certipy, Responder, Ligolo-ng, SecLists and the other curated AUR tools before
the first boot. The temporary repository entry is removed from the target's
Pacman configuration at the end. `legit-tools-install` remains available as a
repair/update helper for an already installed Arch system; it does not touch
shell, editor or desktop configuration.

Use LEGIT OS only for authorized testing, labs and security research.
